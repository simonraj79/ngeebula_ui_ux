# Stakeholder video production

The completed edit presents the Singapore maintenance-planning problem, Ngeebula's five-step workflow, and a controlled synthetic scheduling comparison in **1 minute 54 seconds**.

See [video project and rendering instructions](../../video/README.md), [script/storyboard](SCRIPT_AND_STORYBOARD.md), [news evidence](SOURCES_AND_CLAIMS.md), [capture notes](CAPTURE_NOTES.md), [audio checks](AUDIO_QA.md), and [final verification](VALIDATION.md).

The video is built from real isolated-demo screenshots and original motion graphics. It illustrates the workflow using prepared examples; it does not claim that the draft, proposal and approved record are a single captured transaction. A separate subtitle file accompanies the burned-in captions.
